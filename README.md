# Bank System - Java
This is a simple Banking System developed using **Java**. It allows users to manage their accounts through a command-line interface.

## 🚀 Features
* **Login System:** Secure login for users.
* **Check Balance:** View the current balance of the account.
* **Withdrawals:** Withdraw money safely (updates text files).
* **Deposits:** Add money to the account.

## 🛠️ Technologies Used
* Java (Core)
* File Handling (for data storage)

## 📂 How to Run
1. Clone this repository.
2. Open the project in NetBeans or any Java IDE.
3. Run the `NewMain.java` file.
